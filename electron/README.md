# doon-shell

지금까지 **확정된 결정 세 개만** 반영한 최소 실행체입니다.

- 001 · Electron
- 002 · F11 완전 몰입 — 브라우저 크롬(주소창·탭바·버튼) 없음
- 003 · "OS에 들어온 느낌" — OS 창틀(제목표시줄·최소화/최대화/닫기·리사이즈 테두리)도 없음

그 외의 것(소환 방법, 탭 전환, 홈 화면, 부팅 시퀀스 등)은 아직 제안 단계라
일부러 아무것도 넣지 않았습니다. 그래서 지금 체험할 수 있는 건 딱 하나입니다 —
**켜면 창틀 없이 콘텐츠가 화면 전체를 채운다.**

## 실행

이 실행체는 실제 디스플레이가 있어야 눈으로 확인됩니다.
(원격 환경에서는 화면을 못 보여드려서, 가상 디스플레이로 프레임이 없다는 것만
검증하고 스크린샷으로 남겼습니다 — `docs/` 참고)

```bash
cd electron
npm install
npm start
```

## 확인 방법

전체화면으로 뜬 채, 화면 어디에도 제목표시줄·메뉴줄·버튼이 없고
콘텐츠(구글 검색창)가 화면 가장자리까지 닿는지 보시면 됩니다.

## 나가는 법 (임시)

`Esc` 또는 `Ctrl`/`⌘`+`Q`. 소환 방법(002-1)이 정해지기 전까지의
테스트용 탈출구일 뿐, 설계된 조작이 아닙니다.

## 콘텐츠는 왜 구글인가

"홈 화면"이 뭔지(003-3)는 아직 정하지 않았습니다. 처음 대화에서 예로 드신
"구글 검색창 + F11" 화면을 그대로 채워서, "이게 내 소프트웨어의 평소 상태다"를
체감하시라고 임시로 넣었습니다. 실제 제품에 뭘 채울지는 003-3에서 따로 정합니다.
