# 제품 원칙

기능 목록이 아니라 판단 기준이다. 새 기능을 넣을지 말지 여기서 결정한다.

## 1. 추측하지 않는다. 해석을 보여준다

입력을 주소로 볼지 검색어로 볼지는 **공개된 규칙**으로 정하고, 그 결과와 근거를
입력 중에 항상 한 줄로 띄운다. Enter는 화면에 적힌 그 해석만 실행한다.

> `버전 1.2` → `"버전 1.2" 검색` · 공백 포함 → 검색어

규칙은 `src/core/url.js` 한 파일에 전부 들어 있다. 읽을 수 있고, 테스트되어 있다.

## 2. 입력을 가로채지 않는다

인라인 자동완성 없음. 자동 선택 이동 없음. 제안은 목록으로만 제시하고,
채우려면 <kbd>Tab</kbd>을 명시적으로 눌러야 한다. 타이핑 속도와 경쟁하는 UI를 만들지 않는다.

## 3. 이미 열린 것이 새로 여는 것보다 먼저다

목적지가 이미 탭에 있으면 기본 동작은 **전환**이다. 새 탭은 <kbd>Shift</kbd>+<kbd>Enter</kbd>로
명시할 때만 열린다. 중복 탭은 목록에서 한 줄로 접고 개수를 밝힌다.

## 4. 내 데이터가 웹보다 먼저다

탭 → 북마크 → 기록 → 그다음 웹 검색. 웹 검색 후보는 **사라지지 않되 항상 마지막 줄**이다.
프로모션·광고 결과를 이 목록에 섞지 않는다. 영원히.

## 5. 순위에는 근거가 붙는다

모든 후보는 왜 거기 있는지 배지로 말한다. `이미 열려 있음`, `20시간 전`, `4번 방문`,
`제목 앞부분 일치`. 점수 계산은 `src/core/rank.js` 안에 전부 있고 서버로 나가지 않는다.

## 6. 주소는 문자열이 아니라 구조다

스킴 / 호스트 / 경로 / 파라미터를 각각 조작할 수 있는 조각으로 보여준다.
추적 파라미터는 기본적으로 꺼진 채 표시하고, 복사하면 꺼진 상태로 복사된다.

## 7. 문법은 외우는 게 아니라 발견하는 것이다

접두어는 네 개뿐이고, 하나를 치는 순간 가능한 것이 전부 목록에 뜬다.

| 접두어 | 뜻 |
| --- | --- |
| `!` | 사이트 한정 검색 (`!gh doon`) |
| `@` | 범위 한정 (`@탭`, `@기록`, `@북마크`, `@페이지`) |
| `>` | 명령 (`>탭 정리`) |
| `?` | 무조건 웹 검색 |

설정 화면에 숨은 기능을 만들지 않는다.
