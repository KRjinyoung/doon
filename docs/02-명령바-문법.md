# 명령 바 문법

구현(`src/core/parse.js`)과 1:1로 대응한다. 여기 적힌 것이 곧 동작이다.

## 접두어 없는 입력

규칙 순서대로 판정하고, 판정 근거를 함께 돌려준다.

| 조건 | 결과 | 예 |
| --- | --- | --- |
| 공백 포함 | 검색어 (예외 없음) | `도커 볼륨 마운트` |
| 알려진 스킴 (`http:` `https:` `file:` `about:` …) | 주소 | `about:blank` |
| 알 수 없는 스킴 | 검색어 | `TODO: 내일 할 일` |
| `localhost`, IPv4, `[IPv6]` | 주소 | `localhost:3000` |
| 포트 명시 | 주소 | `10.0.0.5:8080` |
| 점 포함 + 마지막 라벨이 알파벳 2자 이상 | 주소 | `github.com` |
| 점 포함이지만 TLD 형태가 아님 | 검색어 | `버전 1.2`, `3.14` |
| 그 외 | 검색어 | `docker` |

콜론 뒤가 숫자면 스킴이 아니라 포트로 본다. `localhost:3000`이 검색어로 새는 사고를 막는다.

## `!` — 사이트 한정 검색

```
!gh doon browser      → GitHub 안에서 "doon browser" 검색
!npm react            → npm 검색 + "패키지 바로 열기" 후보
!                     → 등록된 별칭 전부 목록으로
```

등록되지 않은 별칭은 **조용히 웹 검색으로 새지 않고** 그렇다고 알려준다.
별칭 목록은 `src/core/registry.js`.

## `@` — 범위 한정

```
@탭 slack        → 열린 탭에서만
@기록 도커        → 방문 기록에서만
@북마크          → 북마크 전체
@페이지 환불      → 현재 페이지 안에서 찾기 (페이지를 떠나지 않음)
```

범위를 한정하면 웹 검색 후보는 목록에 끼어들지 않는다. 한정했으니 한정한 대로 한다.

## `>` — 명령

```
>탭 정리      중복 탭 합치기
>분할         화면 분할
>세션 저장     열린 탭 묶음에 이름 붙이기
>주소 복사     추적 파라미터 없는 주소 복사
>소리 끄기     모든 탭 음소거
```

## `?` — 무조건 웹 검색

```
?github.com   → 주소처럼 생겼어도 검색한다
```

## 키

| 키 | 동작 |
| --- | --- |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>L</kbd>, <kbd>/</kbd> | 명령 바 열기 |
| <kbd>↑</kbd> <kbd>↓</kbd> | 후보 이동 |
| <kbd>Enter</kbd> | 화면에 적힌 해석 실행 |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | 새 탭 강제 (전환 대신) |
| <kbd>Tab</kbd> | 후보를 입력창에 **채우기만** (실행하지 않음) |
| <kbd>Esc</kbd> | 닫기 |

## 순위 규칙

`src/core/rank.js`의 가중치가 전부다.

```
열린 탭        1000
주소 이동       900
북마크          500
방문 기록       400
사이트 검색     300
명령            250
웹 검색          10   ← 언제나 마지막 줄
```

여기에 매치 품질(제목 앞부분 120 / 주소 앞부분 110 / 단어 70 / 부분 30),
최근성(24시간 반감), 방문 횟수(최대 +60)가 더해진다.
여러 단어는 AND로 걸린다 — 한 단어라도 빠지면 후보가 아니다.
